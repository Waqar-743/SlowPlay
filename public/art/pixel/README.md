# Pixel forest artwork

Forest sword poster from [Pixel Sword by diiviikk5](https://github.com/diiviikk5/Hacktemplates/tree/main/templates/pixel-sword), used under the included MIT license.

The arcade adapts its forest, lime, cream, pixel typography, and square framed interface. Decorative fireflies are a small CSS layer; the original WebGL background script is not loaded.

Press Start 2P, Silkscreen, and VT323 are self-hosted in fonts/. Their individual SIL Open Font License notices accompany the fonts.
